# Embragues 25 — sitio web

Landing institucional de Embragues 25, con acceso a [Mercado Libre](https://www.mercadolibre.com.ar/pagina/embragues25) e [Instagram](https://www.instagram.com/embragues25/).

Sitio estático sin frameworks. Para probarlo localmente: `python -m http.server 8000`.

Publicación: GitHub Pages, rama `main`, directorio raíz, dominio `embragues25.com.ar`. Configurar DNS y HTTPS desde GitHub Pages.

La compra, los precios y la disponibilidad se gestionan exclusivamente en Mercado Libre.
